## 🌟 จุดเด่นและฟังก์ชันการทำงาน

### 1. กฎการคิดราคาและการจัดสรรห้องพัก (10 ห้อง)
* **ห้องพักรายชั่วโมง 5 ห้อง (ห้อง 1 - 5):**
  * อัตรา 3 ชั่วโมง = **200 บาท** (ต่อเวลาได้ ชม. ละ 50 บาท)
  * คำนวณเวลาเช็คเอาต์ให้อัตโนมัติ (+3 ชั่วโมงจากเวลาเช็คอิน)
* **ห้องพักรายวัน 5 ห้อง (ห้อง 6 - 10):**
  * เช็คอินก่อน 18:00 น. = **400 บาท**
  * เช็คอินหลัง 18:00 น. = **350 บาท** (ส่วนลดอัตโนมัติ 50 บาท)
  * เช็คเอาต์วันถัดไปก่อน 12:00 น. (เที่ยงวัน)

### 2. ฟังก์ชันสำหรับผู้เข้าพัก (Guest)
* **ระบบจัดเรียงห้องว่างขึ้นก่อน:** ห้องที่ยังไม่ถูกจองจะแสดงอยู่ด้านหน้าเรียงตามเลขห้อง ส่วนห้องที่ถูกจองแล้วจะอยู่ด้านหลังสุด
* **ระบบต่อเวลาพักชั่วคราวด้วยตนเอง:** กดต่อเวลาได้ทันที (+1 ชม. 50฿ / +2 ชม. 100฿) จากหน้าการเข้าพัก
* **ระบบยกเลิกการจอง:** สามารถกดยกเลิกได้ทันทีหากกดจองผิด พร้อมปุ่มส่งหลักฐานขอรับเงินคืนผ่าน LINE หากโอนเงินพร้อมเพย์แล้ว
* **ระบบรีวิวจากลูกค้าจริง:** แสดงคะแนนความพึงพอใจ 4.9/5 ดาว และเปิดให้ผู้เข้าพักเขียนรีวิวความประทับใจได้

### 3. ระบบจัดการหลังบ้าน (Admin Rack)
* ซ่อนมิดชิด 100% สำหรับผู้เยี่ยมชมทั่วไป แสดงเฉพาะเมื่อล็อกอินด้วยอีเมลแอดมิน (`setthawut09902@gmail.com`)
* แสดง Rack 10 ห้องแบบ Real-time พร้อมเวลานับถอยหลัง
* ตรวจสอบสลิปโอนเงิน ยืนยันการจัดส่งของเสริม และสรุปรายรับประจำวัน
